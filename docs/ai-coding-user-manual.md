# AI Coding Skill 使用手册

> 版本: 1.0
> 日期: 2026-07-29

---

## 一、概述

AI Coding Skill 是基于 Claude Code 的自动化代码生成工具，通过读取恒效能平台的需求单，AI 自动分析需求、定位代码、生成修改方案，经人工审核后自动修改代码并提交到 Git 仓库。

### 核心功能

- ✅ MCP 读取效能平台需求单
- ✅ AI 自动分析需求生成任务清单
- ✅ AI 扫描代码仓库，精确定位修改位置
- ✅ 人工审核确认后自动修改代码
- ✅ 自动提交到 Git 仓库

### 适用场景

- 需求单涉及代码修改
- 需要在本地代码仓库中添加新字段、校验逻辑等
- 适合 C++ 代码的维护和修改

## 二、前置条件

### 1. 环境要求

| 工具 | 要求 |
|------|------|
| Claude Code | 已安装并可正常运行 |
| Git | 已安装（用于代码提交） |
| Python | 3.8+（如需使用 CLI 工具） |

### 2. 效能平台权限

- 拥有效能平台的 Access Key
- 可以查询需求单和任务单

### 3. 代码仓库要求

- 必须是 Git 仓库
- 有写入权限
- 建议是无未提交更改的干净状态

### 4. 环境变量设置

在系统环境变量中设置：

```
ACCESS_KEY=你的效能平台AccessKey
```

## 三、使用方式

### 触发方式

在 Claude Code 中直接说出需求：

```
处理需求 {需求编号}，代码目录是 {代码仓库路径}
```

**示例**：

```
处理需求 202607090685，代码目录是 C:/Users/hspcadmin/Desktop/src
```

### 快捷指令

| 指令 | 说明 |
|------|------|
| AI Coding 需求编号 代码目录 | 完整调用 |
| 处理需求 需求编号 | 省略代码目录（需配置） |

## 四、完整执行流程

### Step 1: 读取需求单

AI 通过 MCP 接口读取效能平台的需求详情：

```
[1] MCP 读取需求单
    - 需求: EI接口-港股通指令端资金可用查询
    - 类型: 改进性需求
    - 产品: CP-S000128-3.2
```

### Step 2: 生成任务清单

AI 分析需求，自动生成任务清单：

```
[2] AI 分析需求，生成任务清单
    - 任务编号: T202607290001
    - 任务名称: [改进]港股通指令端资金可用查询增加出参
```

### Step 3: 确认字段

AI 无法生成的字段需要用户确认（直接回车跳过使用空值）：

```
[3] 用户确认任务单字段（AI 无法自动生成）
    - versionNO (版本号): [空]
    - modifierNo (修改人编号): [空]
    - modifierName (修改人名称): [空]
    - projectNo (项目编号): [空]
    - projectName (项目名称): [空]
    - estimateWorkload (预估工时): [空]

    直接回车跳过使用空值，或填写具体值
```

### Step 4: 本地备份

任务单自动备份到本地：

```
[4] 本地备份任务单
    → 保存到: ai-coding/tasks/{需求编号}_{日期}.json
```

### Step 5: 代码扫描

AI 扫描代码仓库，搜索相关代码：

```
[5] 代码扫描和语义匹配
    - 搜索关键词: risk_trade, risk_settle
    - 找到相关文件: src/uft/uft_datamgr.cpp
```

### Step 6: 精确定位

AI 找到精确的修改位置：

```
[6] AI 精确定位修改位置
    - 文件: src/uft/uft_datamgr.cpp
    - 行号: 4861-4862
    - 修改位置: 字段映射字典
```

### Step 7: 生成方案

AI 生成代码修改方案：

```
[7] 生成修改方案
    - 在字段映射字典中增加两个新字段
```

### Step 8: 人工审核

用户审核修改方案：

```
[8] 用户审核确认
    ╔══════════════════════════════════════════╗
    ║ 需求编号: 202607090685                    ║
    ║ 文件: src/uft/uft_datamgr.cpp            ║
    ║ 增加字段: risk_trade_available           ║
    ║           risk_settle_available          ║
    ╠══════════════════════════════════════════╣
    ║ [✅ 审核通过] - 确认修改方案               ║
    ║ [❌ 审核拒绝] - 拒绝修改                  ║
    ║ [💬 补充说明] - 提出修改建议             ║
    ╚══════════════════════════════════════════╝
```

**用户输入**：
- `通过` 或 `1` → 执行修改
- `拒绝` 或 `2` → 取消修改
- 其他文字 → 补充说明

### Step 9: 自动修改

审核通过后，AI 自动修改代码：

```
[9] 自动修改代码
    ✓ 代码已修改
```

### Step 10: Git 提交

修改自动提交到 Git：

```
[10] Git 提交
    → Commit: 3186a1b
```

## 五、代码模板

AI Coding 内置代码模板，确保生成代码符合项目规范：

### 模板 1：参数校验

```cpp
// 获取字段
{field_type} {var_name} = lpUnPack->Get{Method}("{field_name}");
// 校验空值
if ({var_name} == NULL || strlen({var_name}) == 0) {
    lpIUFTContext->nErrorNo = -1;
    lpIUFTContext->SetErrorFileFuncInfo(__FILE__, __LINE__, __func__);
    lpIUFTContext->Debug("{错误信息}, 需求编号: {需求编号}");
    lpIUFTContext->EndProcess(__FUNCTION__, 1);
    return lpIUFTContext->nErrorNo;
}
```

### 模板 2：字段映射

```cpp
// ========================================
// {需求编号} - {描述} (AI Coding 添加)
// ========================================
{"field_name", "字段中文名"},
// ========================================
```

### 模板 3：错误返回

```cpp
lpIUFTContext->nErrorNo = -1;
lpIUFTContext->SetErrorFileFuncInfo(__FILE__, __LINE__, __func__);
lpIUFTContext->Debug("{错误信息}, 需求编号: {需求编号}");
lpIUFTContext->EndProcess(__FUNCTION__, 1);
return lpIUFTContext->nErrorNo;
```

## 八、注意事项

### 1. 代码仓库要求

- 必须是 Git 仓库
- 如果不是 Git 仓库，修改后的文件会备份到 `ai-coding/modified_files/`
- 建议使用干净的仓库（无未提交的更改）

### 2. 修改范围

- AI 适合修改**单文件**或**少量文件**的需求
- 复杂需求可能需要人工介入

### 3. 审核机制

- **修改前必须经过人工审核**
- 审核通过后才会实际修改代码
- 审核拒绝后可以重新分析

### 4. Git 操作

- 默认只提交到本地仓库
- 需要手动 `git push` 推送到远程

## 九、故障排除

### 问题 1：MCP 调用失败

**症状**：读取需求单失败

**排查**：
1. 检查 `ACCESS_KEY` 环境变量是否设置正确
2. 检查网络是否可达效能平台
3. 确认需求编号是否存在

### 问题 2：找不到代码位置

**症状**：AI 无法定位修改位置

**排查**：
1. 检查代码仓库路径是否正确
2. 手动提供更详细的关键词
3. 需求可能不涉及代码修改

### 问题 3：代码仓库无法修改

**症状**：提示不是 Git 仓库

**说明**：
- 修改后的文件会备份到 `ai-coding/modified_files/`
- 需要手动复制到实际代码仓库
